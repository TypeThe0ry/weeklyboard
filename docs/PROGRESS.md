## 行为变更（升级时注意）

1. 确认 AI 计划写入「预估」图层，不再直接写成「实际」。
2. `/api/review?week_key=…` 的「计划」量包含任务的预估时长，即使本周没有排进时间轴。不带 `week_key` 仍返回全部历史合计。
3. 触屏拖动日程要先按住，不再一碰就拖。
4. 备份、订阅链接、番茄钟开关、模板、教程、退出登录都移到了「更多」。
5. `/api/plan/preview` 忽略客户端传来的 `review`，改由服务端重建。

## 已知问题

- 本地排程器不会因为上周完成率低而减少总量，只做避让；真正「少排一些」只有 DeepSeek 路径会做。
- 根目录 `index.html` 是 Vite 入口并依赖 8787 后端；直接用 GitHub Pages 服务 `main` 不可用，线上走 `deploy/`。
